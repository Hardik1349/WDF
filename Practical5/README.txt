CampusConnect - Practical 5
===========================

Files:
- registration.html: student registration form
- js/registration.js: JavaScript validation using regular expressions
- CSS/style.css: existing website styles plus Practical 5 form styles
- index.html, about.html, dashboard.html, events.html, login.html: existing project pages
- style.css: copy of the stylesheet for compatibility

How to run:
1. Extract the ZIP file.
2. Open index.html in a browser, or open registration.html directly.
3. Complete the form and press Register to test validation.

Validation rules:
- Name: letters, spaces, hyphens and apostrophes.
- Email: basic email format.
- Mobile: 10 digits, beginning with 6, 7, 8 or 9.
- Password: at least 8 characters, with uppercase, lowercase, digit and special character.
- Confirm password: must match the password.
- Course and year: required selections.
- Gender: one option must be selected.
- Terms: checkbox must be accepted.

Note:
This is a front-end practical demonstration. A successful message does not save or submit data to a server.
The original home page references images/student.png; that image was not included in the supplied files, so the home page image may not appear unless you add it.
